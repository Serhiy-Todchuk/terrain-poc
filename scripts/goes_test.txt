# GOES-19 observed clouds against the HRRR model (docs/weather_roadmap.md step 3,
# plan item 6): the same views at the cloud quality levels Layers + wind (HRRR
# alone), Satellite observed (each HRRR hour corrected by the GOES-19 scan of the
# weather time, src/CloudBlend.*) and Simple shell, every level picked in the
# Time & weather tab's Quality combo (real clicks; the panel is hidden for the
# shots). A night case (a high deck, no optical depth from COD), a day case (COD),
# scrubbing to the next scan, switching back and forth (corrections reused).
# Needs the network once (HRRR 2026-10-10 17z / 18z and 2026-10-11 00z / 01z;
# GOES-19 scans 2026-10-10 17:01 / 17:16 and 2026-10-11 00:01, ~9 MB each); then
# it replays with --offline.
# Run: TerrainPOC.exe --script ..\..\scripts\goes_test.txt --shot-dir ..\..\shots\goes --offline
# Expected log (one "Clouds: HRRR ... + GOES-19 scan ... -> valid ..." line per
# hour and scan):
#   00:05 (night, scan 00:01): 00z high 54 -> 82 %, middle 33 -> 38 %, low 12 ->
#   15 %, observed from above 11 / 18 / 100 %, tops set 0 / 4 / 78 %, COD 0 %
#   (daylight 0 %); 01z (the deck carried +59 min east) high 52 -> 83 %.
#   17:05 (day, scan 17:01): 17z high 35 -> 67 %, middle 27 -> 34 %, low 6 ->
#   15 %, observed from above 25 / 33 / 100 %, tops set 0 / 7 / 59 %, COD 80 %
#   (daylight 100 %); 18z high 35 -> 70 %, COD 73 %.
#   17:20: the 17:16 scan corrects 17z (high 35 -> 66 %, COD 78 %) and 18z
#   (35 -> 70 %, COD 75 %) again.
#   Back to Satellite observed after another level: no new lines (reused) -
#   6 blend lines in all; 0 errors, 0 warnings. The offline replay logs the same
#   values and writes byte-identical fields_* / goes_* images.
# Images (shot dir): n* = 2026-10-11 00:05, d* = 2026-10-10 17:05; <view>_layers
# vs <view>_satellite (and _shell) from the same camera. Night: the observed deck
# covers more of the box (high 54 -> 82 %), its slab ends at ~10 km instead of
# HRRR's ~14 km. Day: the thick system in the south-west and the deck over New
# York where HRRR has a gap (harbour: overcast instead of a blue gap).
# cloudfields: fields_<valid>_hrrr_* vs fields_<valid>_goes<hhmm>_* (per layer
# cover / base / top / optical depth, the ranges of the goes images);
# goes: goes_<scan>_scan_* (the scan itself, parallax-corrected).
